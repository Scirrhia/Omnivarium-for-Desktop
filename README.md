# Omnivarium for Desktop

Omnivarium is an ebook reader for Windows with **Codex**: a spoiler-aware guide to the people and terms in each book, with every mention. This repository hosts the Windows installer. The source code isn't public.

## Download

**[Download the latest version](https://github.com/Scirrhia/Omnivarium-for-Desktop/releases/latest)** and run `Omnivarium-Setup-<version>.exe`.

- It installs for your Windows account only, with no administrator prompt.
- **Windows SmartScreen will warn you** because the installer isn't code-signed yet. Click **More info → Run anyway**.
- Requires Windows 10 version 1809 or later (x64). The app window uses Microsoft Edge WebView2, which is part of Windows 11 and current Windows 10. Without it, the app opens in your browser.
- Upgrading keeps your library, Codex files, notes and settings. Uninstalling keeps them too: your books stay in `Documents\Omnivarium` and your app data in `%APPDATA%\Omnivarium`.

## What it does

- **Codex:** shows the people and terms you've met so far, in this chapter, or in the whole book, with every mention.
- **Codex Editor:** rename, merge, split and describe entries, and share Codex files or find ones other readers published.
- **Formats:** EPUB, MOBI, AZW3, AZW, PRC, HTML and text PDF. DRM-protected books aren't supported.
- **Reading:** highlights, notes, bookmarks, search, an offline dictionary, read-aloud, and fonts, themes and layouts.
- **Library:** collections, series, genres and tags, free public-domain catalogs, cloud storage, and fanfiction update checks.

Omnivarium has no ads, no analytics and no account. Online features run only when you use them.
